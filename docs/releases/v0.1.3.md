# v0.1.3

## Highlights

- Adds package-managed native PAM mode helpers for Debian/Ubuntu, Fedora/RHEL, Arch, and Alpine Linux-PAM packages.
- Standardizes the operator flow around `pwned-check-pam-enable-dry-run`, `pwned-check-pam-enable-enforce`, and `pwned-check-pam-disable`.
- Updates RPM/authselect and manual-PAM package helpers so dry-run to enforcement switching preserves the original rollback target.
- Documents the signed package repository path for apt, dnf/yum, Arch, and Alpine distribution.

## Operator impact

- Operators no longer need to edit generated package helper files or remember distro-specific low-level commands for normal enablement.
- Package installation still places files only; enablement remains explicit and starts in dry-run mode.
- Arch packages install the helper commands under `/usr/bin`; Debian/Ubuntu, Fedora/RHEL, and Alpine packages install them under `/usr/sbin`.
- Signed distro repositories are still not part of this release. GitHub Releases remain the package distribution channel.

- VM and container package validation covered Debian/Ubuntu package helpers, Fedora RPM/authselect mode switching, Arch package smoke in Docker, and Alpine package/manual-helper smoke on the Alpine VM.

## Known limitations

- Native PAM remains Linux-only.
- Native packages are attached to GitHub Releases but are not yet distributed through signed apt, dnf/yum, Arch, or Alpine package repositories.
- Repository signing keys, repository metadata publication, public key bootstrap docs, and repository-install smoke tests remain the next release-infrastructure step.
