# v0.1.5

## Highlights

- Adds `linux/arm64` Docker PAM smoke coverage in GitHub CI for Debian, Ubuntu, Fedora, and Alpine package installs.
- Keeps `linux/amd64` Docker PAM smoke coverage in the same CI matrix so package install behavior is checked across both release architectures.
- Runs local pre-push native PAM package smoke tests against clean package state on the persistent Ubuntu, Debian, Fedora, Rocky, and Alpine VMs.
- Routes Rocky Linux validation through the persistent Rocky VM instead of a Docker substitute.
- Updates the native PAM validation matrix so architecture and environment coverage are explicit.

## Operator impact

- No checker or native PAM runtime behavior changes are intended in this release.
- Release confidence improves for arm64 Linux package consumers because CI now validates arm64 Docker PAM installs on the distros that publish suitable arm64 images.
- Local maintainer validation now removes any previously installed native PAM package before VM smoke tests, so install, enable, rollback, and removal paths are checked from a clean state.
- Arch package automation remains `linux/amd64` only.

## Validation

- GitHub CI passed on `main` at `f3d99d9` on 2026-05-04, including the amd64 and arm64 Docker PAM smoke matrix.
- Local pre-push validation passed before `main` was pushed at `f3d99d9`, including Go tests, Rust native PAM tests, fuzz smoke, coverage, Docker smoke, VM package smokes, Arch Docker smoke, Arch Docker PAM smoke, and Linux amd64/arm64 package builds.
- Local arm64 Docker PAM smoke passed for Debian stable, Ubuntu 24.04, Fedora latest, and Alpine 3.20 before the CI matrix change was committed.
- The tag-triggered CI and release workflow will rebuild release artifacts from this tag before publishing.

## Known limitations

- Native PAM remains Linux-only.
- Arch packaging remains `linux/amd64` only.
- Native packages are attached to GitHub Releases but are not yet distributed through signed apt, dnf/yum, Arch, or Alpine package repositories.
- Repository signing keys, repository metadata publication, public key bootstrap docs, and repository-install smoke tests remain future release-infrastructure work.
