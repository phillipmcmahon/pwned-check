# v0.3.1

## Highlights

- Corrects native PAM package payload permissions so `pam_pwned_check.so`
  installs as a normal non-executable shared library.
- Tightens apt repository smoke validation to assert the exact Debian/Ubuntu
  multiarch PAM module path.

## Operator impact

- Debian and Ubuntu packages install the PAM module under
  `/lib/<multiarch>/security/pam_pwned_check.so`.
- Fedora/Rocky, Arch, and Alpine install locations are unchanged.
- Operators do not need to change enablement commands; continue to use
  `pwned-check-pam-enable-dry-run`, `pwned-check-pam-enable-enforce`, and
  `pwned-check-pam-disable`.

## Validation

- Version metadata was prepared with
  `make prepare-release-version VERSION=v0.3.1`.
- Local VM smoke validation passed across Ubuntu, Debian, Fedora, Rocky,
  Alpine, and Arch hosts, including configured arm64 VMs.
- The focused apt repository smoke detected the stale pre-fix local apt
  repository package, confirming the new exact-path and mode guard catches the
  previous class of regression.
- GitHub CI on `main` was monitored to completion before the signed release tag
  was pushed.

## Known limitations

- Arch Linux ARM remains outside the release target because Arch Linux ARM is a
  separate downstream ecosystem rather than an official Arch Linux architecture.
- Alpine package repository publication remains Linux-PAM-only; BusyBox-only
  authentication is outside scope.
- macOS and Windows production integrations remain intentionally deferred until
  platform signing and security requirements are designed and validated.
