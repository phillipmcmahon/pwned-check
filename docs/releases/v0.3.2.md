# v0.3.2

## Highlights

- Publishes a repository-backed patch release for the apt multiarch smoke fix
  and the CI fuzz-smoke stability fix.
- Keeps the native PAM package repository flow aligned with immutable GitHub
  Release assets before package repositories are updated.
- Revalidates live package-manager installation paths after repository
  publication.

## Operator impact

- Debian and Ubuntu operators do not need `dpkg-dev` installed for repository
  smoke validation or package-manager installation checks.
- Package installation and enablement commands are unchanged:
  `pwned-check-pam-enable-dry-run`, `pwned-check-pam-enable-enforce`, and
  `pwned-check-pam-disable`.
- Operators should expect signed apt, RPM, Arch, and Alpine repositories to
  serve `0.3.2` after publication completes.

## Validation

- Version metadata was prepared with
  `make prepare-release-version VERSION=v0.3.2`.
- GitHub CI on `main` passed for
  `02c4d502cd31a3abbd423075ec6d9e0704941c9e` after release prep:
  <https://github.com/phillipmcmahon/pwned-check/actions/runs/25441985668>.
- Local validation, tag-triggered release asset publication, GitHub Pages
  repository publication, endpoint checks, and live package-manager smoke
  results are completed as part of the v0.3.2 release process.

## Known limitations

- Arch Linux ARM remains outside the release target because Arch Linux ARM is a
  separate downstream ecosystem rather than an official Arch Linux architecture.
- Alpine package repository publication remains Linux-PAM-only; BusyBox-only
  authentication is outside scope.
- macOS and Windows production integrations remain intentionally deferred until
  platform signing and security requirements are designed and validated.
